# 10-14-occupational-health-surveillance-checker 项目计划总览

**项目**：职业健康监护合规核查工作台（用人单位职业健康合规工具，Windows 桌面 + CLI 双形态，危害因素×检查项×周期监护矩阵 + 覆盖度核查 + 双版本规则集 + 批量对账 + 报告导出）
**方法论**：ai-tool-project-sprint（标准条款库 + 版本化监护规则集 + 合成监护档案真值基准 + 证据指纹 + 离线交付）
**项目系列**：同系列第 18 题（前作名称与业务领域按脱敏纪律不入公开仓，见「决策记录」品牌隔离项）
**命名约定**：本地目录 `10-14-occupational-health-surveillance-checker`（`10-14`=2026-10-14 日期标签）；**GitHub 仓库名 = `occupational-health-surveillance-checker`（纯净名，去日期前缀）**，沿用系列惯例 `yuluo554/<kebab-name>`；署名 `yuluo554`（LICENSE/pyproject 一致）。
**定位宣言（v1）**：把"岗位接触哪些危害因素 → 应做哪些检查项、多久一次 → 这次做全了没有 → 缺项漏检怎么成表"整条链做成**规则化、可复现、逐项挂条款依据**的本地工作台——LLM 聊天给不了持久监护规则库、危害因素×检查项目×周期的确定性矩阵与全量覆盖比对，本工具是职业健康监护合规自查与专项检查前的口径防线。
