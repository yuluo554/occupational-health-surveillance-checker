## 一、项目介绍

《职业健康监护技术规范》是开展职业健康检查的基本技术依据。**国家卫生健康委于 2025-08-20 发布国卫通〔2025〕10 号通告，发布强制性国家职业卫生标准 GBZ 188—2025《职业健康监护技术规范》（代替 GBZ 188—2014），自 2026-08-01 起施行，GBZ 188—2014 同时废止**。这是截至基准日 **2026-10-14** 职业健康监护领域**最近一次实质换版**：新标准前言逐条列出主要技术变化，包括**新增**多种危害因素的监护（甲苯、溴丙烷、碘甲烷、环氧乙烷、氯乙酸、铟及其化合物、煤焦油、煤焦油沥青、石油沥青、β-萘胺、金属及其化合物粉尘、硬金属粉尘、毛沸石粉尘、低温、激光、蜱传脑炎病毒、布氏疏螺旋体、人免疫缺陷病毒作业人员及刮研作业、井下工人长期蹲跪姿/爬行/侧卧/肩扛作业、制造业工人长时间腕部重复作业或用力作业、参与突发事件处置的应急救援作业人员等）、**新增**部分危害因素的应急健康检查与离岗时检查、**删除**甲苯二异氰酸酯与结核病/肝炎病防治作业、**删除**上岗前/在岗期间/离岗时的"选检项目"（仅保留应急检查选检项）、**新增**附录 C 推荐性检查与附录 E/G 报告文书模板、**新增**生物接触限值生物标志物检测。

用人单位侧的真实痛点是三条：**①矩阵难记**——GBZ 188 按危害因素逐节规定目标疾病、检查对象、检查内容（必检/选检/补充）、检查周期，组合数量庞大，靠人翻标准必然漏项；**②新旧口径易混**——2026-08-01 起适用新标准，但历史年度的监护档案、正在执行的监护计划可能仍按 2014 版编制，混用即失真；**③核查无据**——专项检查要"每个岗位的危害因素 → 应检项目 → 实际体检项目 → 缺什么"逐条对得上并挂条款，人工比对慢且不可复现。

目前开源侧**"国标口径的职业健康监护合规核查工作台"近乎空白**（GitHub 检索职业健康监护相关仓库仅零星 0–1 star 工具，且均为境外/医疗通用系统）；商业侧为体检机构系统与咨询服务，没有"版本化规则 + 确定性监护矩阵 + 批量档案对账 + 证据指纹"的完整开源实现。

## 二、任务要求

> 首期范围限定为 **GBZ 188—2025 的接触化学因素（第 5 章）与物理因素（第 6 章）主要危害因素 + GBZ 188—2014 用于历史年度对照**；特殊作业人员（第 7–9 章）留扩展。全部模块遵循"**未挂原文核对不得落库/生效/进入核查路径**"的确定性纪律。

### 1）危害因素 × 检查项目 × 周期 监护矩阵引擎（确定性内核，亮点）

- 把 GBZ 188—2025 各危害因素节次编码为**结构化监护规则**（危害因素编号、名称、目标疾病、检查对象/接触人群、上岗前/在岗期间/离岗时/应急四类检查的**必检项目与补充项目**、检查周期、条款依据）；
- 输入岗位档案（危害因素、接触浓度/强度、工龄、上次检查日期），**确定性推导**该岗位人员**应做的检查项目清单与应检周期**；
- 输出**清单 + 逐项条款依据**（结论旁挂"第 X.X 节"），四类检查时点分别判定；
- 检查周期、项目构成一律从规则包读取，**禁止硬编码**。

### 2）监护档案覆盖度核查（交付物进入工作流，亮点）

- 输入**劳动者职业健康监护档案**（体检日期、检查时点类型、实检项目清单、结论），逐人逐项比对"应检项目 vs 实检项目"；
- 输出 **符合 / 部分符合（缺项清单）/ 不符合 / 不适用** 四态 + 缺项对应的条款依据；
- **周期合规判定**：距上次检查时长是否超过规则包规定周期；
- **结论项合规**（如体检结论的构成要求、疑似职业病告知义务）按条款核对。

### 3）双版本规则集与差异对照器（工程亮点）

- 规则包按 **`依据文件 × 版本`** 组织：`GBZ 188—2014` 与 `GBZ 188—2025` 各成独立规则集，条款/项目/周期逐条独立挂原文来源；
- **版本差异报告**：一键列出两版在危害因素覆盖、检查项目构成、检查周期上的**实质差异**（新增危害因素、删除的危害因素与项目、选检项目调整等），差异条目直接源自新标准前言的"主要技术变化"；
- **历史年度回算**：指定体检年度即自动锚定该年度适用的规则版本，杜绝"用 2025 版标准重算 2014 口径旧档案"；
- 每条规则挂 `status`（`verified`/`pending`），**未核对不得进入核查路径**。

### 4）批量子档扫描与对账（M3 级，批量扫描对账）

- 支持目录/清单批量读入**多企业 × 多岗位 × 多人员**监护档案，逐份核查，**失败件隔离不中断**（坏格式、缺字段、危害因素不识别单列原因码）；
- **跨轮对账**：本轮结果与上轮结果比对，输出"新增缺项 / 已补齐 / 持续缺失"三集合，供整改闭环；
- **群体统计**：按危害因素/岗位汇总"应检人数 / 实检人数 / 缺检人数"，供管理者整改排期。

### 5）内置评测基准（零 API 依赖）

- **监护矩阵基准**：程序化构造危害因素 × 检查时点 × 项目构成的期望清单，验证矩阵推导与规则包一致；
- **覆盖度判定基准**：程序化构造带植入真值的合成监护档案（如"某苯作业人员缺离岗时检查""某噪声作业人员检查周期超期"），验证四态判定；
- **双版本对照基准**：同一岗位在两版规则下的期望结果差异，验证版本切换；
- **误报对照集**：显式声明"应零命中"的干净档案，基准层只读声明、不自选考卷。

### 6）证据链与报告导出（可核证交付物）

- 每个核查结论可挂**证据**（本地文件引用与指纹），监护档案与结果整体计算 **sha256 指纹**随底稿固化；
- 一键导出**监护合规核查报告**（Markdown + XLSX）：含岗位危害因素画像、应检/实检/缺项清单与条款依据、周期合规、群体统计、整改台账、版本坐标与证据指纹；
- 报告头固定输出**规则包坐标**（依据版本 + 版本号 + 生成时间）。

### 7）桌面与 CLI 双形态

- 同一套引擎既有命令行、也有桌面界面；**界面只渲染引擎结果、零判定逻辑**（GUI 服务层是唯一引擎调用点，保证界面与 CLI 结论一致）。

## 六、边界与非目标

- **不做**：不做医学诊断与体检结论判定（不替代医师判断）；不做职业病诊断与鉴定；不做体检机构的排班/收费系统；不做生物样本或检测数据采集；不对接监管申报接口。
- **首期范围**：GBZ 188—2025 接触化学因素（第 5 章）与物理因素（第 6 章）主要危害因素 + GBZ 188—2014 用于历史年度对照；特殊作业人员（第 7–9 章）留扩展。
- **合规红线**：**全本地处理存储、零上传**；监护档案可能含劳动者个人健康信息（敏感个人信息），工具默认不联网；**免责声明强制**：输出为基于标准的监护合规检查发现，不构成医学意见、职业病诊断或行政认定，正式结论以职业健康检查机构与卫生健康行政部门口径为准；规则包未挂原文核对（`status=pending`）不得进入核查路径。
- **数据纪律**：演示与基准一律使用**合成监护档案**，禁止真实劳动者健康信息入库；合成人员统一使用虚构姓名代号与测试身份号段（如 `90000000…SYN` 号段），按白名单登记；证据样本仅留结构说明。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
