## 四、合成数据纪律

- **假人员与假身份白名单**：合成劳动者统一使用虚构姓名代号（如"示例人员 A-001"）＋虚构身份号段（保留测试号段 `90000000…SYN`）；合成企业使用虚构名称（如"示例制造（合成）有限公司"）＋虚构统一社会信用代码（同测试号段）。**不得使用任何真实姓名、身份号、真实企业名称或真实体检数据。**
- **健康信息属敏感个人信息**：合成档案仅含"岗位危害因素、接触时长、体检日期、检查时点类型、实检项目代码、结论代码"等**结构化字段**，不构造任何真实医学指标、影像或诊断文字。
- **植入真值**：合成监护档案由 `tools/gen_synthetic.py` 生成时同时产出**期望核查结论**（应检项目集合、缺项集合、周期是否超期），真值随档案入库；引擎以独立实现路径对账。
- **算例覆盖**：化学因素（如苯、铅及其无机化合物）、物理因素（如噪声、高温）各设算例；含**周期边界档案**（恰好到期 / 差一天）、**缺项档案**（缺离岗时检查、缺某一必检项目）、**新旧版本差异档案**（同一岗位在 2014/2025 两版下应检项目不同）。
- **误报对照集**：真值库显式声明"应零命中"的干净档案（应检项目齐备、周期合规）与"应降级"的档案（项目名称别名可映射 → 只报 `warning`），基准层只读该声明，不自行挑选对照档案。
- 生成器为**唯一写入者**：产物禁手改；再生成须逐字节一致（守门测试）。
